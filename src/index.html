EVDS Web Servis Kılavuzu

EVDS web servisi kullanmak için kayıtlı kullanıcı olmanız gerekir (Bkz. Üye İşlemleri Kılavuzu), "Benim Sayfam" bağlantısını seçiniz. Belirlediğiniz kullanıcı adını ve parolanızı giriniz. Kullanıcı adınız üzerine tıklayarak menüden "Profilim" seçiniz. Sayfanın alt bölümünde API Key Kopyala seçimi ile API anahtarınızı alınız. (Şekil 1). API Anahtarı (key=XXXXXXX) her kullanıcı için farklı tanımlanır. DİKKAT: Web servis çağrılarında "key" değerini HTTP Request Header'a eklemeniz gerekmektedir. Key değerini iletmeyenler veya yanlış gönderenler 403 Forbidden hatası alacaktır. Şekil-1: API Anahtarı Farklı işlevdeki parametreler "&" işareti ile ayrılır. EVDS'de yer alan veriler en sık olarak günlük frekansta güncellenmektedir. Dolayısıyla Web servis yöntemi ile veri alımında günde bir kez veri çekilir. Ayrıca ihtiyaç duyulan, aynı veri grubuna ait serileri birlikte kodlayarak tek çağrı ile veri çekilmesi de yararlı olacaktır. Web Servis isteklerindeki tarih aralığı maksimum 1000 gözlem değeri kadar olacaktır. Bu değerden yüksek bir aralık girilir ise, Bitiş Tarihi'nden geriye doğru 1000 gözlem değeri kadar gidilecek ve ekrana bu veriler getirilecektir. Parametre Adı Açıklama 1. Seri Parametreleri Seri kodları gösterilir. Birden fazla seri seçilmesi durumunda, seri sayısı kadar parametre alır, seri kodları "-*" işareti ile ayrılır. Parametre Adı Açıklama 1.a. Tarih Parametreleri tarihini gösterir. Tüm tarihler mutlaka gg-aa-yyyy formatında Başlangıç tarihini gösterir. Tüm tarihler mutlaka gg-aa-yyyy formatında yyyy formatında yazılmalıdır. Bitiş tarihini gösterir. Tüm tarihler ve saatler "gg-aa-yyyy" biçimindedir.
